# Stormy TikTok Extension

Chrome extension for capturing TikTok sessions and syncing them to Stormy.ai platform.

## Installation

### Step 1: Download the Extension
Click the download link above, or visit the [Releases](https://github.com/OneInterface/stormy-tiktok-extension-releases/releases/latest) page.

### Step 2: Extract the Files
Unzip the downloaded file to a folder on your computer.

### Step 3: Install in Chrome
1. Open Chrome and navigate to `chrome://extensions`
2. Enable **Developer mode** (toggle in the top right corner)
3. Click **Load unpacked**
4. Select the folder where you extracted the extension files

### Step 4: Configure the Extension
1. Visit your [Stormy.ai Connected Accounts](https://stormy.ai/connected-accounts) page
2. The extension will automatically configure itself when you open this page
3. Look for the green checkmark indicating "Extension Configured"

### Step 5: Sync Your TikTok Session
1. Open TikTok in a browser tab and make sure you're logged in
2. Click the Stormy TikTok extension icon in your Chrome toolbar
3. Click **Sync TikTok Session**
4. You should see "Connected as @your_username" when successful

## Usage

Once connected, you can:
- Send TikTok DMs directly from the Stormy.ai dashboard
- Manage your TikTok messaging campaigns
- Track influencer conversations

## Troubleshooting

### Extension Not Detected
- Refresh the Connected Accounts page after installation
- Make sure Developer mode is enabled in Chrome extensions

### Sync Errors
- Ensure you're logged into TikTok in your browser
- Close all TikTok tabs except one and refresh it
- Try syncing again

### Connection Issues
- Check that you've visited the Connected Accounts page to configure the extension
- Verify the extension is enabled in `chrome://extensions`
